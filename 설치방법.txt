==========================================================
   외국어 영상 TTS - 설치 방법 (꼭 읽어주세요)
   한국어 대본을 일본어/영어 음성으로 만드는 프로그램입니다.
==========================================================

이 폴더의 시작 파일을 더블클릭하면, 처음 한 번만 자동으로 설치된 뒤
프로그램이 브라우저에서 열립니다. 인터넷이 연결된 곳에서 진행하세요.


[ 공통 - 먼저 확인 ]
 1. 받은 압축파일(zip)을 "반드시 풀어서" 사용하세요.
    압축 안을 들여다본 채로 바로 실행하면 안 됩니다.
 2. 첫 실행은 인터넷이 꼭 필요합니다.
    (프로그램과 음성 모델을 내려받습니다. 대략 1~2GB, 몇 분 ~ 십여 분)
 3. 두 번째 실행부터는 인터넷 없이도 빠르게 열립니다.
 4. 진행 중에 뜨는 검은 창(윈도우)/터미널(맥)은 닫지 말고 기다리세요.
    창을 닫으면 프로그램이 종료됩니다.


==========================================================
   [ 윈도우 Windows ]
==========================================================

 1) 받은 zip 파일을 마우스 우클릭 -> "압축 풀기" 로 폴더에 풉니다.
 2) 풀린 폴더에서   START-Windows.bat   을 더블클릭합니다.
 3) 검은 창이 뜨고 자동 설치가 진행됩니다. (처음만, 몇 분)
    잠시 후 브라우저(크롬/엣지)가 자동으로 열리면 준비 완료입니다.
 4) 다 쓰면 검은 창을 닫으면 프로그램이 종료됩니다.
    다음부터는 다시 START-Windows.bat 만 더블클릭하면 됩니다.

  * 윈도우 주의사항 *
  - "Windows의 PC를 보호했습니다" / SmartScreen 안내가 뜨면:
      "추가 정보" -> "실행" 을 누르세요. (직접 만든 도구라 안전합니다.)
  - 파이썬(Python)이 없으면 자동 설치를 시도합니다.
    자동 설치가 안 되면, 검은 창의 안내대로 아래에서 직접 설치하세요:
      https://www.python.org/downloads/release/python-3119/
    -> "Windows installer (64-bit)" 를 받아 설치
    -> [중요] 설치 첫 화면 맨 아래 "Add python.exe to PATH" 를 꼭 체크!
    -> 설치 후 START-Windows.bat 을 다시 더블클릭
  - 백신 프로그램이 막으면 잠깐 허용/예외 처리해 주세요 (오탐입니다).


==========================================================
   [ 맥 Mac ]
==========================================================

 ※ 최신 맥(예: Sequoia, Tahoe)에서는 "우클릭 -> 열기" 방법이 막혔습니다.
   ("Apple이 악성 코드가 없음을 확인할 수 없습니다" 창만 뜨고 안 열립니다.)
   그래서 아래 "터미널" 방법으로 실행하세요. 맥 버전에 상관없이 됩니다.

 1) 받은 zip 파일을 더블클릭해서 폴더로 풉니다. (맥 기본 압축 해제)
 2) 터미널을 엽니다.
       Command(⌘) + Space  ->  "터미널" 입력  ->  Enter
 3) 터미널 창에   bash   라고 친 다음 한 칸 띄웁니다. (아직 Enter 누르지 마세요)
 4) Finder 에서  START-Mac.command  파일을 끌어다가 터미널 창 안에 놓습니다.
       (파일의 경로가 자동으로 입력됩니다)
 5) Enter 를 누릅니다.
       -> 자동 설치가 진행되고, 잠시 후 브라우저가 열립니다.
       -> 첫 실행은 인터넷이 꼭 필요하며 몇 분 걸립니다.

  * 맥 주의사항 *
  - "Apple이 ... 악성 코드가 없음을 확인할 수 없습니다" 창이 떠도 정상입니다.
    "휴지통으로 이동"을 누르지 말고, 위 터미널 방법으로 실행하세요.
    (직접 만든 도구라 안전합니다.)
  - 다음부터 "더블클릭"으로 열고 싶다면 한 번만 더 해두세요:
    터미널에   chmod +x   라고 친 뒤 한 칸 띄우고,
    START-Mac.command 를 끌어다 놓고 Enter. (이후엔 더블클릭으로 열립니다.)
  - 파이썬 3.11 이 없다고 나오면 아래에서 설치하세요:
      https://www.python.org/downloads/release/python-3119/
    -> "macOS 64-bit universal2 installer" 를 받아 설치한 뒤, 위 2)~5) 를 다시 합니다.


==========================================================
   [ 사용법 - 간단 ]
==========================================================
 1) 언어 / 목소리 / 속도 선택  (미리듣기로 목소리를 들어볼 수 있어요)
 2) 대본을 붙여넣기
 3) 포맷(영상 편집은 WAV / 공유는 MP3)과 저장 폴더 선택
 4) [음성 생성] -> 폴더에 저장되고 바로 재생/다운로드
    (자세한 설명은 프로그램 화면 맨 위의 "도움말" 을 펼쳐 보세요)


막히는 부분은 화면을 캡처해서 보내주시면 도와드리겠습니다.
