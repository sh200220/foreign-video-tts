# 외국어 영상용 TTS (한국어 · 일본어 · 영어)

무료 오픈소스 모델 **Kokoro**(영어·일본어, Apache 2.0)와 **Supertonic**(한국어, 상업 사용 가능)으로
영상 내레이션 음성을 만듭니다. **GPU 없이 CPU에서 동작**하고, 두 가지 방식으로 쓸 수 있습니다.
추가로 **고품질·감정 모드**(Chatterbox, MIT)를 설치하면 감정 강도를 조절하는 상급 음성도
만들 수 있습니다(옵션 — NVIDIA GPU가 있으면 자동 가속, 없으면 CPU로 느리게 동작):

| 방식 | 대상 | 설명 |
|------|------|------|
| 🖥️ **웹 UI** (`app.py`) | 누구나(비개발) | 브라우저에서 클릭·드롭다운으로 생성 |
| ⌨️ **CLI 일괄 처리** (`tts.py`) | 대량 작업 | 폴더에 대본 넣고 한 번에 변환 |

> ✅ Windows(Python 3.11, i7-1260P)에서 한국어·영어·일본어 생성 검증 완료. 맥은 동일 코드로 준비됨(첫 실행 테스트 권장).

## 🚀 빠른 시작 — 설치 한 번 + 실행 (더블클릭)

압축을 푼 폴더에서 **OS에 맞는 파일 하나만 더블클릭**하면 됩니다. 첫 실행 때 필요한 것을 자동으로 설치한 뒤 브라우저가 열립니다(이후엔 바로 실행).

### 윈도우
- **`START-Windows.bat` 더블클릭** — 그게 전부입니다.
  - 처음엔 파이썬 3.11 + 라이브러리를 자동 설치합니다(몇 분, 인터넷 필요).
  - 파이썬이 없으면 자동 설치를 시도합니다(winget). 자동 설치가 안 되면 안내대로
    [python.org 3.11](https://www.python.org/downloads/release/python-3119/)에서 한 번 설치
    (설치 화면에서 **"Add python.exe to PATH" 체크**) 후 다시 더블클릭하세요.

### 맥
1. (처음 한 번) **`START-Mac.command` 우클릭 → 열기** → 뜨는 창에서 **열기** 클릭.
   - 인터넷에서 받은 앱이라 나오는 안전 확인입니다. **두 번째부터는 그냥 더블클릭**하면 됩니다.
   - 파이썬 3.11이 없으면 안내가 나옵니다 →
     [python.org 3.11 (macOS)](https://www.python.org/downloads/release/python-3119/) 설치
     (또는 `brew install python@3.11`) 후 다시 열기.

> 압축은 맥 기본 압축 해제(더블클릭)로 풀면 **실행 권한이 유지**되어 `chmod` 없이 바로 됩니다.
> 혹시 더블클릭 시 텍스트로만 열리면, 터미널에서 `chmod +x START-Mac.command` 한 번 후 다시 시도하세요.

> 처음 실행 시 모델(~327MB)·발음 데이터가 자동 다운로드됩니다(한 번만, 인터넷 필요).
> 한국어는 **첫 생성 때** 별도 모델(~404MB)을 한 번 더 자동 다운로드합니다.

### 웹 UI 사용법
브라우저 화면에서 (앱 상단 **도움말**을 펼치면 간단 사용법이 나옵니다):
- **언어** (한국어, 영어 미국/영국, 일본어) → 선택 시 **목소리** 목록이 자동으로 바뀜
- **목소리** 드롭다운 (영어 20종 / 일본어 5종 / 한국어 10종 — 여 F1~F5·남 M1~M5) · **속도** 슬라이더 (0.5~2.0, 한국어는 0.7 미만이면 0.7로 자동 조정)
- **목소리 섞기**(체크): **목소리 2** 드롭다운과 **비율 슬라이더**가 나타남 →
  같은 언어의 두 목소리를 비율로 혼합 (왼쪽=목소리1, 오른쪽=목소리2). **한국어는 미지원**(자동 숨김)
- **미리듣기**: 고른 목소리(또는 믹스)를 짧은 샘플로 바로 들어볼 수 있음 (현재 속도 반영, 파일 저장 안 함)
- **대본**: 텍스트 붙여넣기 (아래에 **글자 수·예상 길이**가 표시됨)
- **쉼 태그**: 대본 속 원하는 곳에 `[쉼:1.5]` 를 쓰면 그 자리에서 **정확히 1.5초** 쉼 (0~10초).
  줄 하나가 태그뿐이면(예: `[쉼:2]` 단독 줄) **자막 없는 장면 전환 쉼**이 됨
- **대화 모드**(체크): **화자 슬롯 4개**에 이름과 목소리(드롭다운)를 넣거나
  **[대본에서 화자 자동 인식]** 버튼으로 대본 속 `이름:` 들을 자동으로 채운 뒤,
  대본 줄 앞에 `이름:` 을 붙이면 화자별 목소리로 합성 (인터뷰·대화 영상용).
  화자는 **다음 화자 표시가 나올 때까지 유지**되어 긴 대사도 이름 한 번이면 되고,
  `기본:` 을 쓰면 기본 목소리(내레이션)로 복귀. 슬롯마다 **[듣기]**로 바로 확인.
  자막에는 화자 이름이 빠지고 말한 내용만 기록
- **파일로 만들기**(접힌 메뉴 펼치기): `.txt` **여러 개**를 올리면 **파일별로 한 번에** 생성(각 파일 이름으로 저장) — 일괄 작업, 진행률 표시
- **추가 옵션**(접힌 메뉴): **발음 교정**(`원문=읽을말` 한 줄에 하나로 잘못 읽는 단어 교정) · **문단 사이 쉼**(줄바꿈마다 무음 넣어 호흡 조절)
- **포맷**: **WAV**(편집용 무손실) · **MP3**(공유) · FLAC · OGG
- **자막(.srt)도 같이 저장**(체크): 음성과 같은 이름의 **타이밍 자막 파일** 생성 → 영상 편집기에서 캡션 동기화에 사용
- **자막 한 줄 최대 글자 수** 슬라이더: 긴 자막을 지정 글자 수 이하 조각으로 자동 분할(시간은 글자 수 비례).
  0 = 제한 없음, 권장: 영어 42 / 한국어·일본어 20~24
- **무음 다듬기 + 페이드**(체크): 클립 앞뒤의 빈 정적을 자르고 짧은 페이드로 "툭" 끊김 제거
- **장면별로 나눠 저장**(체크): 대본을 **빈 줄로 장면을 구분**해 문단마다 따로 파일(+자막)로 저장 — 장면 단위 영상 조립에 편리
- **음량 정규화**: **끔 / 피크**(최대치 맞춤) **/ 방송용(LUFS)**(유튜브 등 체감 음량 -14 LUFS, 클립 간 볼륨 균일)
- **저장 폴더**: 아래 **[폴더 찾아보기…]**(창에서 클릭) · **[바탕화면]** · **[다운로드]** · **[기본 폴더]** 버튼으로 쉽게 고르거나 직접 입력
- **파일 이름에 날짜·시간 자동 추가**(체크): 덮어쓰기 없이 매번 새 파일로 저장
- **파일 이름** 지정 → **[음성 생성]** → 재생/다운로드, 지정 폴더에 저장. **[저장 폴더 열기]** 로 폴더를 바로 열 수 있음
- 마지막으로 쓴 **언어·목소리·속도·포맷·폴더 설정은 자동으로 기억**되어 다음에 열면 그대로 복원됩니다

### 고품질·감정 모드 (옵션)

1. 폴더의 **`SETUP-고품질모드.bat`**(맥은 `.command`)을 **한 번** 더블클릭 — 별도 환경에 Chatterbox 엔진 설치.
   NVIDIA 그래픽카드가 있으면 **자동으로 GPU 가속 버전**이 설치됩니다.
2. 앱에서 언어를 **"영어/일본어/한국어 (고품질·감정)"** 으로 선택.
3. 속도 슬라이더 자리에 **감정 강도**(0 밋밋 ~ 1 과장)와 **말 페이스**(0.2 느긋 ~ 0.8 빠릿)
   슬라이더가 나타납니다 — 자동 보정 없이 직접 조절합니다.
   팁: 감정을 올리면 말이 빨라지는 경향이 있으니 페이스를 낮춰 균형을 잡으세요.
4. 첫 생성 때 모델(~3GB)을 자동 다운로드합니다(인터넷 1회).

제약: 내장 목소리 1개 → 목소리 섞기·대화 모드 미지원. CPU에서는 생성이
오디오 길이의 약 6~7배로 느리고(배치용), GPU(예: RTX 2070 이상)에서는 실시간급입니다.
생성 음성에는 비가청 워터마크(Perth)가 포함됩니다(청취 품질·상업 이용에 영향 없음).

## ⌨️ CLI 일괄 처리 (대량 작업용)

`scripts/en/`·`scripts/ja/`·`scripts/ko/` 에 `.txt`(UTF-8)를 넣고:
```bash
# 윈도우 (맥은 ./.venv/bin/python tts.py ...)
.\.venv\Scripts\python.exe tts.py                          # 전부 (WAV)
.\.venv\Scripts\python.exe tts.py --lang ja --format mp3   # 일본어만, MP3 로
.\.venv\Scripts\python.exe tts.py --lang ko --voice M2     # 한국어, 남성 목소리
.\.venv\Scripts\python.exe tts.py --lang en --voice am_michael --speed 1.1
# 목소리 섞기: 기본 목소리 70% + af_bella 30% (Kokoro 언어만)
.\.venv\Scripts\python.exe tts.py --lang en --voice2 af_bella --mix 0.3
```
옵션: `--format {wav,mp3,flac,ogg}`(기본 wav), `--voice2 NAME`(믹스용 둘째 목소리),
`--mix 0~1`(voice2 비중, 기본 0.5=균등). `--voice2` 는 단일 언어(`--lang en|ja`)에서만(한국어 미지원).
→ `output/en/`·`output/ja/`·`output/ko/` 에 같은 이름으로 생성.

## 🔧 문제 해결
- **(윈도우) `import torch ... c10.dll WinError 1114`**: 최신 torch가 안 맞습니다. 고정 버전 재설치:
  `.\.venv\Scripts\python.exe -m pip install "torch==2.5.1+cpu" --index-url https://download.pytorch.org/whl/cpu`
  (이미 `requirements.txt`에 반영됨 — torch를 임의로 올리지 마세요.)
- **(윈도우) `onnxruntime ... DLL 초기화 루틴을 실행할 수 없습니다`**: 같은 계열 문제입니다.
  `.\.venv\Scripts\python.exe -m pip install "onnxruntime==1.20.1"` 로 고정 버전 재설치
  (이미 `requirements.txt`에 반영됨 — onnxruntime을 임의로 올리지 마세요.)
- **기존 설치 사용자**: 한국어 추가 후 처음엔
  `.\.venv\Scripts\python.exe -m pip install -r requirements.txt` 를 한 번 다시 실행하세요.
- **(윈도우) 파이썬 자동 설치 실패**: [python.org 3.11](https://www.python.org/downloads/release/python-3119/)
  설치("Add python.exe to PATH" 체크) 후 `START-Windows.bat` 다시 더블클릭.
- **(맥) `.command` 가 안 열림**: `chmod +x START-Mac.command` 후 우클릭→열기.
- **저장 폴더 / 미리듣기**: 저장 폴더가 **홈 폴더 하위**면 브라우저 미리듣기까지 됩니다. 홈 밖(예: 다른 드라이브)이면 파일은 저장되지만 미리듣기가 안 뜰 수 있어요(파일은 정상). FLAC·OGG는 브라우저에 따라 미리듣기가 안 될 수 있으나 저장·다운로드는 정상.
